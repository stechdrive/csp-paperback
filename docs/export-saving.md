# フォルダ出力の名前と上書き

手動の全件・選択出力とデスクトップのクイック書き出しは、同じ保存計画と保存アダプターを使う。出力方式の永続設定は作品の合成設定・Undoと分け、上書き許可は永続化しない。

## 保存前に決めること

全出力の名前を解決してから選択項目を抽出する。直接出力ではフラット名を使用し、階層設定を書き換えない。パス用のサニタイズと、区切り文字を含めて置換するファイル名用のサニタイズを使い分ける。

保存先を読み取り、同名の既存画像、新しい画像、フォルダとの競合を計画する。確認中はレンダリングもファイル・フォルダの作成も行わない。大小文字・Unicode NFCで等価な名前を同名と扱い、等価な既存名が複数あれば、どれかを上書きせず新しい名前へ回避する。連番を付けた後も拡張子とUTF-8の長さ制限を守る。

バッチ内で割り当てたパスは実行中だけ予約する。保存先の既存画像への上書き許可があっても、今回の別カットの出力は上書きしない。キャンセルは残りのバッチを止める。通常の読み込み・保存エラーは当該カットを失敗として後続を続ける。

## 保存の保証範囲

デスクトップ版は選択・起動引数で許可されたパスをRust側でも確認する。同じディレクトリの一時ファイルへ画像を書き、同期後に差し替える。新規保存には既存パスを置換しないコミットを使う。計画後に同名が作られた場合も既存ファイルを上書きせず別名へ回避する。保存・コミットの失敗は名前の競合とは分け、無条件に再試行しない。フォルダ・シンボリックリンクは上書き対象にしない。

ブラウザ版はFile System Access APIの書き込みストリームを使い、失敗時はabortする。保存先の列挙と保存直前の確認を行うが、同APIにはネイティブの新規作成専用コミットに相当する操作がない。他のアプリやタブが同時に同じパスを作成する競合について、ネイティブ版と同じ完全な非上書き保証はできない。

上書きは画像ごとの置換であり、フォルダ全体の同期や一括トランザクションではない。今回対象外の古い画像は削除しない。途中で失敗した場合、完了済みの保存は残る。

## 検証

仮想セルのPSD保存は[保存アダプターのテスト](../src/test/platform/psd-save.test.ts)で保存先選択の先行、キャンセル・生成失敗時の無書き込み、書き込み失敗時のabort、ネイティブの原子的差し替え経路を確認する。

Vitestでは既存ファイル・フォルダと今回の出力の衝突、長い日本語名・禁止文字・予約名・正規化、確認前の無変更、キャンセル、バッチ内の保護、選択出力の名前、保存エラーを確認する。Playwrightではブラウザの実ファイルハンドルを使って上書き・別名保存・キャンセルと設定復元を検証する。Rustテストでは実ファイルの置換、新規作成の競合、途中書き込み・コミット失敗時の旧内容保護を検証し、リリース時はWindows/macOS両方で実行する。

## 仮想セルのPSD保存

通常のJPEG／PNG出力とは別の単一ファイル保存で、ZIP・フォルダ分けの設定や出力対象の絞り込みを適用しない。
ファイル名は仮想セル名に`.psd`を付け、既存のサニタイザーで禁止文字・予約名・UTF-8長を調整する。
書き出し内容は[仮想セルのPSD出力](compositing-engine.md#仮想セルのpsd出力)を参照。

デスクトップ版はPSD保存ダイアログで選んだパスへ、既存のRust一時ファイル・差し替え処理を使って保存する。
保存先パスのスコープ検査とフォルダ・シンボリックリンクの拒否は画像出力と共通で、許可する拡張子にPSDを加える。
ブラウザ版はFile System Access APIがあれば保存先を先に選び、PSD生成成功後に書き込みストリームを開く。書き込み失敗時はabortし、非対応ブラウザではBlobをダウンロードする。
保存先選択のキャンセルとPSD生成失敗では既存ファイルを書き換えない。PSD生成中も通常出力と同じ進捗表示・操作ロックを使う。
